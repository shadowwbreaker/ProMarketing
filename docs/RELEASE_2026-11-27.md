## Находки и исправления

| Находка | Что сделано |

| Прямой API разрешал CORS только старому домену. Основной адрес ссылок оставался прежним | CORS принимает основной и прежний адреса. `FRONTEND_URL` переведён на `https://www.yourvideoteam.agency`. |
| Нетекстовый код 2FA мог прерывать обработку с HTTP 500 | Вход, подтверждение и отключение отклоняют неверный тип или формат с клиентской ошибкой. Строка из шести цифр и защита от повторного использования сохранены. |
| Readiness обращался к PostgreSQL и Redis при каждом запросе | Последний результат проверок хранится в памяти процесса до пяти секунд. HTTP 200/503 и формат ответа сохранены. |

| README обещал демоданные при обычном запуске | Отдельно описаны обычный запуск и изолированная конфигурация тестов. Исторические записи сохранены. |

## Проверки

- Изолированный Docker и [GitHub CI](https://github.com/shadowwbreaker/ProMarketing/actions/runs/46021473107): 208 серверных тестов, Ruff, проверка миграций. CI также прошёл 15 фронтенд-тестов, lint, TypeScript и production build.
- [beta-ops](https://github.com/shadowwbreaker/ProMarketing/actions/runs/46021473125) завершился успешно. Новых миграций для исправлений нет.
- На исходной бете прошли 14 браузерных сценариев и отдельные проверки QR 2FA и бета-покупки. Переписка и покупка остались в одном диалоге с уведомлениями без ручной перезагрузки.
- На публичном сайте пустая форма входа с валидным CSRF дошла до `400 validation_error`, запрос без токена вернул 403. Прямой API вернул заголовки CORS для обоих разрешённых доменов. Readiness подтвердил доступность PostgreSQL и Redis, каталог, соглашение и политика вернули HTTP 200.
- На публичные адреса подавались только штатные запросы. Отправка реального письма и полный вход через TikTok не проверялись. Адрес возврата в Login Kit должен совпадать с адресом в [инструкции беты](BETA_VERCEL.md).

Решение D-029 и контракт API дополняют прежние записи. Для отката проверьте подходящие версии в Vercel и сохранённый SHA ветки перед выпуском.
